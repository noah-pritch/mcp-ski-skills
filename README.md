# mcp-ski-skills

The team's MCP Ski plugin for Grok: one plugin (`mcp-ski-skills`, shown as "MCP Ski") with
the mcp-ski connector (`https://mktgapi.mcp.ski/mcp/sse`) and shared skills.

Skills only reach Grok Bot when they ship in a plugin that also has an MCP server, from a public repo.
After a push: Grok dashboard → Plugins → Marketplaces → Team marketplace ⋯ → Refresh.
